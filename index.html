Cloud API Keys

Get keys free: Google (console.cloud.google.com → enable Drive API + Picker API, create API key + OAuth Client ID with your site URL as an authorized origin), Dropbox (dropbox.com/developers/apps), Microsoft (portal.azure.com → App registrations, add Files.Read scope, add your site URL as a redirect URI).
